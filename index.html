두 보드는 자동으로 서로 덮어쓰지 않습니다. 필요한 시점에 전체 선수·라인업·전술을 복사할 수 있습니다. 복사 전 데이터 백업을 권장합니다.

동기화 대상: 선수 정보 · 참석 명단 · 5쿼터 라인업 · 전술판 위치 · 화살표 · 메모. 현재 보고 있는 탭/쿼터는 기기별로 유지됩니다. 여러 기기에서 동시에 수정하면 마지막으로 서버에 저장된 내용이 우선할 수 있습니다.

공식 팀 보드는 로그인하지 않은 방문자도 열람할 수 있습니다. 감독·승인된 코치만 Google 로그인 후 수정할 수 있습니다. Firebase 콘솔에서 공식 팀 보드 공개 읽기 규칙을 직접 게시해야 하며, GitHub 규칙 파일을 올리는 것만으로는 적용되지 않습니다.

안전한 사용을 위해 초기 연결 전 ↓ 데이터 백업을 권장합니다. Firebase 설정값은 웹 앱용 공개 설정이며 서비스 계정 키·비밀번호·관리자 비밀키는 절대로 웹페이지에 넣지 않습니다.
