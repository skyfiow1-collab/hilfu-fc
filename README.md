# HILFU FC v8.2 — 선수 포지션 수정 + 실시간 동기화 상태 표시

## 변경 사항
- 선수 수정 후 주/가능 포지션을 즉시 카드에 다시 표시하고, 실제 저장한 값을 화면 하단 메시지로 확인합니다.
- 개인 보드와 공식 팀 보드에 각각 **기기 저장 / 저장 대기 / 서버 저장 중 / 저장 완료 / 실시간 동기화 / 저장 오류** 상태 표시줄이 나타납니다.
- 서버 저장 성공 시각은 '이 기기 마지막 저장 확인'으로 보존되므로 실시간 구독 메시지에 의해 저장 완료 흔적이 사라지지 않습니다.
- 개인 보드와 공식 보드 복사(v8.1), 17개 포메이션, 전술판, PNG, OCR, 자동 편성 등 기존 기능을 유지합니다.

## GitHub Pages 업데이트
이 패키지의 **index.html**, **firebase-sync.js** 파일만 GitHub 저장소 `skyfiow1-collab/hilfu-fc`의 같은 파일에 덮어씁니다. Commit changes 후 Pages 배포 성공을 확인하고 강력 새로고침하거나 URL 끝에 `?v=8.2`를 붙여 접속합니다.

## Firebase
- **Firestore 규칙**, **Firebase 설정 파일**, 데이터베이스 컬렉션을 변경할 필요 없습니다.
- 기존 로컬 저장 키와 Firestore `hilfuStates/{uid}`, `hilfuTeams/official` 경로 유지.
- 먼저 앱의 '↓ 데이터 백업'으로 JSON 백업을 권장합니다.
- 상태 표시줄에서 `기기 저장`은 **서버 업로드 성공이 아닙니다.** 개인 클라우드 연결 절차를 완료해야 실시간 동기화됩니다.
- `저장 대기`나 `서버 저장 중`일 때는 다른 화면으로 이동하거나 새로고침하지 말고 저장 완료를 확인합니다.
- 서버 저장 완료 여부는 실서비스 Firebase 접속 상태에 따라 확인해야 합니다.
